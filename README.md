# Beat Parry

박자에 맞춰 다가오는 몹을 정확한 타이밍에 쳐내는 리듬 패링 게임. 설치 없이 브라우저에서 바로 실행됩니다. 소리는 전부 Web Audio로 합성합니다.

**플레이:** https://skdyzlzl56-art.github.io/BeatParrying/

## 조작

| 환경 | 왼쪽 패링 | 오른쪽 패링 | 시작 |
|---|---|---|---|
| 키보드 | `A` / `←` | `D` / `→` | `Space` / `Enter` |
| 모바일·마우스 | 화면 왼쪽 절반 터치 | 화면 오른쪽 절반 터치 | 화면 터치 |

모바일은 가로 화면을 권장합니다. 우측 상단 **스테이지 선택**으로 원하는 스테이지와 보스를 바로 고를 수 있습니다.

## 규칙

- 몹은 박자에 맞춰 눈금자를 따라 다가와 **7박째**에 공격합니다. 같은 방향의 몹은 한 번의 패링으로 함께 쳐낼 수 있습니다.
- **PERFECT**(±60ms)만 콤보가 +1 오릅니다. EARLY/LATE는 콤보 1칸 하락, 실패는 HP -1에 콤보 4칸 하락, 허공 패링(공격이 없을 때 입력)은 콤보 1칸 하락입니다.
- 콤보 레이어(2·4·6·8·10·13)가 찰수록 배경 음악에 하이햇, 스네어, 베이스, 아르페지오, 멜로디, 옥타브가 하나씩 쌓이고 화면 연출도 화려해집니다.
- **꾹 누르기:** 누를 타이밍에 눌러 유지하다가 뗄 타이밍에 뗍니다. 롱홀드는 길이가 곡에 맞춰 정해지고, 유지하는 동안 반대쪽에서 내려오는 비트를 쳐낼 수 있습니다.
- 스테이지 1~24를 깨면 보스(BOSS1~3, NORMAL / HARD)가 나옵니다. 보스 HP바는 곡의 남은 시간입니다.

## 로컬 실행

빌드가 없습니다. `index.html`을 브라우저로 열거나 정적 서버로 실행하면 됩니다.

```
npx serve .
```

## 구성

- `index.html`: 페이지, 스테이지 선택 메뉴
- `main.js`: 엔진(판정, 오디오, 그리기)
- `stages.js`: 몹, 편성, 스테이지별 곡, 보스 대본
